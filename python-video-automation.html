Step 1 — Convert any 16:9 video to vertical 9:16

The core operation. The source stays centered, the background is a blurred, scaled-up version of the same frame. This is the filter chain from the production pipeline:

ffmpeg -i input.mp4 -vf "
  split=2[bg][fg];
  [bg]scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,boxblur=20:5[bgblur];
  [fg]scale=-1:1080[fgscale];
  [bgblur][fgscale]overlay=(W-w)/2:(H-h)/2
" -c:v libx264 -preset fast -crf 23 -c:a copy output_vertical.mp4

What each piece does:

  • split=2 — duplicates the input into two streams
  • [bg]scale=1080:1920:crop=1080:1920,boxblur=20:5 — scales the background up to fill the vertical frame, crops the overflow, blurs it
  • [fg]scale=-1:1080 — scales the foreground to 1080px tall, keeping aspect ratio
  • overlay=(W-w)/2:(H-h)/2 — centers the sharp foreground over the blurred background

Run time: ~20–60 seconds per video on a laptop CPU. No GPU needed.

Step 2 — Burn in captions

Subtitles from an SRT file, burned into the video:

ffmpeg -i input.mp4 -vf "subtitles=subs.srt:force_style='FontName=Arial,FontSize=22,PrimaryColour=&H00FFFFFF,OutlineColour=&H00000000,Outline=2,Shadow=0,Alignment=2,MarginV=40'" -c:v libx264 -preset fast -crf 23 output.mp4

If you have a transcript but no SRT, Python can generate one from a word list with approximate timestamps. For precise alignment, use a free tool like whisper.cpp or the Fish Audio API's word timestamps.

Step 3 — Generate narration with free TTS

The production pipeline uses Fish Audio's free tier. One API call per scene:

import requests

API_KEY = "your-fish-audio-key"
voice_id = "27316bff07cf4c839800f240ba9f50b0"

def tts(text, out_path):
    r = requests.post(
        "https://api.fish.audio/v1/tts",
        headers={"Authorization": f"Bearer {API_KEY}",
                 "Content-Type": "application/json"},
        json={"text": text, "voice_id": voice_id, "format": "mp3"},
        timeout=60)
    r.raise_for_status()
    with open(out_path, "wb") as f:
        f.write(r.content)
    print(f"OK: {out_path} ({len(r.content)} bytes)")

tts("Hello, this is a test of the free TTS voice.", "scene_01.mp3")

Free tier: generous daily limit. The voice sounds human, not robotic.

Step 4 — Pull stock b-roll automatically

Both Pexels and Pixabay offer free APIs. Pexels needs a browser User-Agent header (Cloudflare blocks bare requests). Pixabay requires per_page ≥ 3.

import requests

PEXELS_KEY = "your-pexels-key"

def search_pexels(query, per_page=5):
    r = requests.get(
        "https://api.pexels.com/videos/search",
        headers={"Authorization": PEXELS_KEY,
                 "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64)"},
        params={"query": query, "per_page": per_page, "size": "medium"},
        timeout=30)
    r.raise_for_status()
    videos = r.json()["videos"]
    results = []
    for v in videos:
        files = sorted(v["video_files"], key=lambda f: f["width"], reverse=True)
        results.append({"url": files[0]["link"], "duration": v["duration"]})
    return results

clips = search_pexels("technology code screen")
for i, clip in enumerate(clips):
    print(f"Downloading clip {i}: {clip['url']}")
    r = requests.get(clip["url"], timeout=60)
    with open(f"broll_{i:02d}.mp4", "wb") as f:
        f.write(r.content)

Step 5 — Batch process a folder

The real value of automation is doing 50 files at once. Here is a batch wrapper around the vertical converter:

import os, subprocess

def batch_convert(input_folder, output_folder):
    os.makedirs(output_folder, exist_ok=True)
    files = [f for f in os.listdir(input_folder) if f.endswith((".mp4", ".mov"))]
    print(f"Found {len(files)} videos to convert")
    for i, fname in enumerate(files, 1):
        inp = os.path.join(input_folder, fname)
        out = os.path.join(output_folder, f"vertical_{fname}")
        print(f"[{i}/{len(files)}] Converting {fname}...")
        cmd = [
            "ffmpeg", "-i", inp,
            "-vf", "split=2[bg][fg];[bg]scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,boxblur=20:5[bgblur];[fg]scale=-1:1080[fgscale];[bgblur][fgscale]overlay=(W-w)/2:(H-h)/2",
            "-c:v", "libx264", "-preset", "fast", "-crf", "23",
            "-c:a", "copy", out, "-y"
        ]
        subprocess.run(cmd, check=True)
        print(f"  Done: {out}")
    print(f"All {len(files)} videos converted.")

batch_convert("C:/Users/you/videos/", "C:/Users/you/vertical/")

Step 6 — Concatenate clips

Stitch multiple clips into one video. Write a file list, then concat:

# files.txt:
# file 'scene_01.mp4'
# file 'scene_02.mp4'
# file 'scene_03.mp4'

ffmpeg -f concat -safe 0 -i files.txt -c copy final.mp4
